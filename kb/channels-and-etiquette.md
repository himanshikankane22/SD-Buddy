# KB-012 | Channels & Communication Etiquette

> Audience: L1 Service Desk | Owner: Service Desk Manager | Source: ITIL Service Desk practice, internal SOP

## Purpose
Consistent, professional handling across all channels so every interaction is logged, verified, and resolvable.

## Channel-specific rules
1. **Call**
   - Greet with team + name: "Thank you for calling the IT Service Desk, this is <name>."
   - Verify identity using KB-001 questions before any account action.
   - Confirm resolution back to the caller; ask if anything else is needed.
2. **Chat**
   - Keep sentences short; confirm the user is at their desk/device.
   - **Never** paste temp passwords or BitLocker keys in chat (log retention/security).
   - Use quick-reply options when possible to speed resolution.
3. **Email**
   - Acknowledge receipt with a ticket number and expected SLA.
   - Request missing details; do not auto-resolve without verification.
   - Be mindful of auto-replies / distribution-list floods.
4. **Portal / self-service**
   - Ensure the ticket is routed correctly; chatbot can capture initial triage so the agent can pick up with full context.

## Tone
- **Empathetic but efficient**: acknowledge frustration without over-apologizing.
- **Clear, non-jargon**: "What it means / what we will do / when you'll hear back".
- **Honest**: don't promise a time you can't keep; if it needs L2, say so and give the ticket number.
- Never blame the user; treat the issue as the enemy.

## Verification at intake (every channel)
- Standard 5 security questions (KB-001) for any identity/access action (password, MFA, BitLocker, SAP).
- For lower-risk informational queries, lighter verification is acceptable (name + employee code).

## Handoff etiquette
- Before escalating, the ticket must have: verified caller, category, priority, full description, attempted steps.
- Give the receiving team a verbal/chat heads-up for P1/P2.
